# Description of Program
# Purpose
This programme is to calculate the theoretical price and Greeks using Black-Scholes formulae for European options. Call, put, binary call as well as binary put is included.

However, as the program is using closed-form expression, American options could not be calculated.

# Usage
After giving exougenous parameters such as volatility, strike price and underlying asset price etc., the program would automatically calculate the theoretical price.

I provided two programs for users, where the `EUOptionPricer.py` could display results for all type of options, and the `EuropeanOptionCalculator.py` allows users to choose a particular type of options to calculate.

All formulae used for calculating and pricing are same in two programs.
